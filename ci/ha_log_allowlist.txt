# Allowlist for ci/check_ha_log.py
#
# Each entry is a regular expression on its own line. The line before it
# must be a comment that gives the reason. An entry matches a whole log
# record (the first line plus its traceback lines). Keep this file short.
# An entry hides a real problem, so fix the cause when you can.
#
# Example:
#
# Reason: the test config uses a fake dog that does not exist.
# \[custom_components\.pawsistant\] Dog 'nobody' does not exist

# The seeded test storage (tests/integration/ha_config/.storage/pawsistant) already
# has a pet named Buddy. tests/integration/test_lifecycle.py::TestAddRemoveDog adds a
# pet named Buddy again, so the service logs this error. The pattern names the logger,
# the service, and the full message for Buddy only. A duplicate for any other name is
# still reported.
\[custom_components\.pawsistant\] pawsistant\.add_dog: Pawsistant: a dog named 'Buddy' already exists

1"""Export and import of all Pawsistant data. 

2 

3This module is the Pawsistant side of Home Keeper's combined export and import (see 

4Home Keeper's ``docs/INTEGRATING.md``, section "Join the export and import"). Home 

5Keeper puts the ``data`` that :func:`build_export` makes in a section of its own 

6export file. Later, maybe on a different install, it gives that section back to 

7:func:`plan_import` as the ``document``. 

8 

9The 2 functions here are pure. They import no Home Assistant code and do no I/O: 

10 

11* :func:`build_export` turns a snapshot of the store into a portable document. 

12* :func:`plan_import` compares a document with a snapshot of the store and returns an 

13 :class:`ImportPlan`. The plan holds the full report (counts, records, problems) and 

14 every write. It does not write. The store applies a plan that has no error. 

15 

16Rules of the import: 

17 

18* It is an upsert. A dog matches by id, then by name (case-insensitive). A care 

19 schedule matches by id, then by its pair of dog and event type. An event matches by 

20 id. The import never deletes a record that is not in the document. 

21* A document with a ``format`` higher than :data:`FORMAT` is refused. 

22* A care schedule is exported without its Home Keeper ``task_id``, because that id is 

23 known only to 1 install. The reconcile in ``care_link`` makes the task again. 

24"""

100def build_export(snapshot: dict[str, Any]) -> dict[str, Any]: 

101 """Return the portable ``data`` document for *snapshot*. 

102 

103 *snapshot* has these keys: 

104 

105 * ``dogs`` — ``{dog_id: {name, breed, birth_date, species}}`` 

106 * ``event_types`` — the stored event type overrides (a ``None`` value is a 

107 tombstone for a built-in type) 

108 * ``button_metrics`` — the stored button metric overrides 

109 * ``care_schedules`` — ``{schedule_id: {...}}`` 

110 * ``shown_types`` — ``{dog_id: [event_type, ...]}`` 

111 * ``events`` — every event of every year file 

112 """ 

113 dogs = [ 

114 {"id": dog_id, **{k: dog[k] for k in DOG_FIELDS if k in dog}} 

115 for dog_id, dog in snapshot.get("dogs", {}).items() 

116 ] 

117 dogs.sort(key=lambda d: (str(d.get("name", "")).lower(), d["id"])) 

118 

119 schedules = [ 

120 {"id": schedule_id, **{k: v for k, v in schedule.items() if k != "task_id"}} 

121 for schedule_id, schedule in snapshot.get("care_schedules", {}).items() 

122 ] 

123 schedules.sort(key=lambda s: s["id"]) 

124 

125 events = [dict(event) for event in snapshot.get("events", [])] 

126 for event in events: 

127 if "timestamp" in event: 127 ↛ 126line 127 didn't jump to line 126 because the condition on line 127 was always true

128 event["timestamp"] = _export_timestamp(event["timestamp"]) 

129 # Newest first, as in the year files. The id breaks a tie so that 2 exports of 

130 # the same data are equal. 

131 events.sort(key=lambda e: str(e.get("id", ""))) 

132 events.sort(key=lambda e: _sort_key(e.get("timestamp")), reverse=True)

134 return {

136 "dogs": dogs, 

137 "event_types": dict(snapshot.get("event_types", {})), 

138 "button_metrics": dict(snapshot.get("button_metrics", {})), 

139 "shown_types": { 

140 dog_id: list(types) 

141 for dog_id, types in snapshot.get("shown_types", {}).items()

143 "care_schedules": schedules, 

144 "events": events, 

145 }

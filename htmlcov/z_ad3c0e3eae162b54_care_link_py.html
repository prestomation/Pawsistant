1"""Optional link to the Home Keeper task tracker. 

2 

3Pawsistant is one example client of Home Keeper's public, integration-agnostic 

4task-contribution contract (see Home Keeper's ``docs/INTEGRATING.md``). Everything 

5Home-Keeper-specific lives in this single module so the rest of Pawsistant stays 

6unaware of it; if Home Keeper isn't installed, every function here degrades to a 

7no-op. 

8 

9The link works in both directions, behaving like "the same button": 

10 

11* **Pawsistant → Home Keeper** — when a care activity that has a schedule is logged, 

12 :func:`complete_task` marks the linked Home Keeper task done (passing our 

13 :data:`ORIGIN` marker). 

14* **Home Keeper → Pawsistant** — Home Keeper fires ``home_keeper_task_completed`` on 

15 every completion; :func:`parse_completion_event` recognises the ones that belong to 

16 us so the caller can mirror them into a logged event. 

17 

18Undo travels the same two ways, because a mistaken "done" is as much a shared fact as 

19the "done" itself. Deleting a logged event calls :func:`delete_completion`, and Home 

20Keeper's ``home_keeper_task_uncompleted`` comes back through 

21:func:`parse_uncompletion_event`. Both directions identify the completion by its 

22timestamp, which is how Home Keeper keys its own history. 

23 

24Loop prevention uses two independent guards: the ``origin`` marker (we ignore the echo 

25of a completion or undo we initiated), and the caller mirroring inbound changes by 

26writing straight to the store rather than re-entering the ``log_event`` / 

27``delete_event`` service paths. 

28"""

411async def reconcile(hass: HomeAssistant, store) -> None: 

412 """Self-heal the link in both directions. 

413 

414 Recreates Home Keeper tasks for schedules whose task is missing (covering tasks a 

415 user deleted directly in Home Keeper, or schedules created while Home Keeper was 

416 absent), and for schedules whose task is still there, drops mirrored events left 

417 behind by completions that were undone while we weren't listening (see 

418 :func:`_heal_orphaned_mirrors`). 

419 

420 Best-effort and guarded — does nothing if Home Keeper or ``list_tasks`` is 

421 unavailable. 

422 """ 

423 schedules = store.get_care_schedules() 

424 if not schedules or not home_keeper_available(hass) or not _has(hass, "list_tasks"): 

425 return 

426 try: 

427 resp = await hass.services.async_call( 

428 HK_DOMAIN, "list_tasks", {}, blocking=True, return_response=True 

429 ) 

430 except Exception as err: # noqa: BLE001 

431 _LOGGER.warning("Home Keeper list_tasks failed during reconcile: %s", err) 

432 return 

433 live = {t["id"]: t for t in (resp or {}).get("tasks", []) if t.get("id")} 

434 for schedule_id, schedule in schedules.items(): 

435 task = live.get(schedule.get("task_id")) 

436 if task is not None: 

437 await _heal_orphaned_mirrors(store, schedule, task) 

438 continue 

439 new_task_id = await create_task(hass, store, schedule_id, schedule) 

440 if new_task_id and new_task_id != schedule.get("task_id"): 

441 await store.update_care_schedule(schedule_id, task_id=new_task_id) 

442 _LOGGER.info( 

443 "Recreated missing Home Keeper task for care schedule %s", schedule_id
